# 手机公网访问

让顾客通过 HTTPS 链接直接在手机浏览器打开交互界面，不需要安装 App、连接同一 Wi-Fi，或保持店家电脑开机。

## 部署到 Netlify 后

- 已部署到 Netlify：前端静态资源 + `netlify/functions` 提供 `/api/config`、`/api/reviews`。
- Netlify 端固定为真实模式（演示开关已在该路径关闭），因此**必须配置 `DEEPSEEK_API_KEY`**；未配置会报错而非演示。
- 页面右上角为“AI 评价助手”，生成走 DeepSeek 真实接口。

## 手机使用

1. 在手机浏览器打开发布后的 HTTPS 链接。
2. 选择界面语言、评价语言、感受标签和平台，点击生成。
3. 修改文案，核对后勾选确认，再复制。
4. 若手机浏览器限制自动复制或弹窗，用文本框长按复制，并使用页面的手动平台链接。

页面采用标准网页技术，面向 iOS Safari、Android Chrome、鸿蒙等现代浏览器。不能保证已停止维护的旧浏览器或所有第三方内置浏览器行为一致；不同地区网络也可能影响访问，最终以真实手机与网络打开链接确认。

## 构建与部署

- 本地运行：`npm.cmd run build`，然后 `npm.cmd start`（后端 + 前端）。
- 部署 Netlify：见 `Netlify接入DeepSeek.md`。用 `部署到Netlify.cmd` 或仓库连接，**不要拖拽整个文件夹**（会带大量无关文件且函数部署不正确）。
- 后续修改源码后，用同一个网站地址重新发布。

## 密钥与安全

- DeepSeek Key 只放在服务端/Netlify 环境变量，**不要填进网页或提交到版本库**（`.env` 已 gitignore）。
- 真实生成会消耗 DeepSeek 账户余额，也受 Netlify 当前免费套餐额度约束。
