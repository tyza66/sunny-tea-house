# 操作与配置清单

## 阶段 1：体验现有项目

1. 双击项目根目录的 `启动项目.cmd`。
2. 按窗口显示的地址打开浏览器。
3. 先不选标签，确认“生成我的评价”不可点击。
4. 选一个、再选第二个标签，确认其余标签变灰；取消一个后可以换选。
5. 生成 Google 文案，检查英文初稿。
6. 切换小红书，按提示重新生成，检查中文初稿和字数。
7. 编辑、核对并勾选确认，然后复制。

## 阶段 2：真正调用 AI

你需要准备：DeepSeek API Key、可用的 API 账户余额。

1. 在 `.env` 设置 `DEMO_MODE=false`。
2. 填写 `DEEPSEEK_API_KEY`，不需要发到聊天窗口。
3. 停止并重新启动服务。
4. 每个平台各生成一次，核对语言、标签和长度。
5. 若失败，按维护手册检查密钥、余额和网络。

## 阶段 3：平台入口

当前假设的店名和城市已配置为 Sunny Tea House / San Jose，无需你补充虚构地址。

如果以后改为真实店铺，你需要决定或提供：

| 项目 | 当前设置 | 需要你做什么 |
| --- | --- | --- |
| 品牌风格 | 已确认暖色茶饮风 | 无需再次选择 |
| Google 链接 | 空白，只复制 | 提供真实商家“索取评价”链接 |
| 小红书入口 | 官方首页 | 若有经验证的官方入口，可替换 |
| 企业微信 | 关闭 | 决定是否启用，启用时本地填写机器人地址 |
| 运行范围 | 本机 | 公开上线时选择服务器、域名和预算 |
| 草稿保存 | 不保存，刷新清空 | 若需要历史记录，确定保存期限与用途 |

## 阶段 4：后续调整如何提出

可以直接描述页面、操作步骤与期望，例如：

> 手机上标签文字太小，请调大，并保持最多选择两个。

或者使用维护手册里的问题模板。修改只应发生在本项目目录；不要把其他 AI 工具的配置加入项目。

## 阶段 5：确认可上线的范围

本轮已完成可本地运行的项目。真实 AI、真实商家跳转和真实企业微信发送，需要上述账号和配置后再联调。没有这些信息不影响演示与界面验证。
