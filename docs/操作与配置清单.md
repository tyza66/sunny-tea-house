# 操作与配置清单

本项目只在 GitHub Actions 与 Netlify 上运行，仓库内不保留本地启动脚本与 `.env` 模板。

## 阶段 1：在线体验现有项目

1. 打开演示地址 https://tyza66.github.io/sunny-tea-house/ （或 Netlify 部署后的地址）。
2. 先不选标签，确认“生成我的评价”不可点击。
3. 选一个、再选第二个标签，确认其余标签变灰；取消一个后可以换选。
4. 生成 Google 文案，检查英文初稿（演示模式返回本地示例文案，页面有明确标注）。
5. 切换小红书，按提示重新生成，检查中文初稿和字数。
6. 编辑、核对并勾选确认，然后复制。
7. 右下角「本地设置」按钮可在本机浏览器改店铺信息、换 AI 服务商（任意 OpenAI 兼容接口 + 模型名 + 自己的密钥），保存后刷新仍在；这是 GitHub Pages 版唯一的「环境变量」入口，配置只存在本机。

## 阶段 2：在 Netlify 接入真实 AI

你需要准备：任意 **OpenAI 兼容**服务商的 API Key（默认 DeepSeek）与可用的 API 账户余额。

1. 在 Netlify 后台打开 **Project configuration → Environment variables**，添加 `DEMO_MODE=false`。
2. 填写 `AI_API_KEY`，Scope 需包含 Functions，上下文选 Production；值只粘贴完整 Key，不需要发到聊天窗口。
3. 换服务商时再填 `AI_BASE_URL` 与 `AI_MODEL`（默认已指向 DeepSeek，无需改动）；旧名 `DEEPSEEK_API_KEY`/`DEEPSEEK_MODEL` 仍作别名有效。
4. 保存后到 **Deploys → Trigger deploy** 触发一次重新部署，等构建完成；运行中的函数不会自动读到新值。
5. 每个平台各生成一次，核对语言、标签和长度。
6. 若失败，按维护手册检查密钥、余额和网络；完整排查顺序见 [AI 服务商接入](AI服务商接入.md)。

## 阶段 3：平台入口

当前假设的店名和城市已配置为 一茶一言 / San Jose，无需你补充虚构地址。

如果以后改为真实店铺，你需要决定或提供：

| 项目 | 当前设置 | 需要你做什么 |
| --- | --- | --- |
| 品牌风格 | 已确认「宣纸墨」素雅极简（宣纸底 + 暖墨字 + 印章朱砂信号色） | 想换风格可再描述 |
| Google 链接 | 空白，只复制 | 提供真实商家“索取评价”链接 |
| 小红书入口 | 官方首页 | 若有经验证的官方入口，可替换 |
| 企业微信 | 关闭 | 决定是否启用，启用时在 Netlify 环境变量填写机器人地址 |
| 运行范围 | GitHub Pages（静态演示）+ Netlify（真实 AI） | 公开上线时确认域名与预算 |
| 草稿保存 | 不保存，刷新清空 | 若需要历史记录，确定保存期限与用途 |

## 阶段 4：后续调整如何提出

可以直接描述页面、操作步骤与期望，例如：

> 手机上标签文字太小，请调大，并保持最多选择两个。

或者使用维护手册里的问题模板。修改只应发生在本项目目录，推送到 `main` 后由 GitHub Actions 与 Netlify 自动构建发布；不要把其他 AI 工具的配置加入项目。

## 阶段 5：确认可上线的范围

本轮已完成可在线部署的项目：静态演示由 GitHub Pages 发布，真实 AI 由 Netlify 承载。真实商家跳转和真实企业微信发送，需要上述账号和配置后再联调。没有这些信息不影响演示与界面验证。
