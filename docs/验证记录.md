## 自动验证的行为

- 标签最多两个，拒绝空标签、重复标签、未知平台与未知标签。
- 演示模式两种语言内容与标签对应。
- 真实模式缺少 Key 时拒绝启动；公开配置不包含密钥。
- DeepSeek 请求地址与认证头正确；上游错误、空内容、截断内容有对应处理。
- 小红书超过 150 字符时最多重试一次；手动编辑超限不能继续复制。
- 企业微信默认不发送；模拟启用时，摘要和初稿通知流程正确。
- 限流在达到上限时返回 429。
- 标签或平台改变后初稿过期，必须重新生成。
- 重新生成失败保留编辑内容。
- 剪贴板成功、失败回退、弹窗成功和受阻回退均已验证。
- 本地演示文案在五种语言、两个平台与 6 种轮换说法组合下均完整可读；同一组选择重复生成会轮换开头与结尾。
- 小红书演示文案全部控制在 150 字符内，与服务端提示词的字数限制一致。
- 平台、语言或标签片段缺失时直接报错，不再静默输出空文案。

### GitHub Pages 能力边界与免密钥公共接口实测

- GitHub Actions 只在推送时执行构建，密钥即使注入也会进入公开仓库的构建产物，等于泄露；页面也无法同步等待 workflow 跑完再返回结果。因此 Pages 只能承载静态前端，不能替代服务端，真实 AI 生成必须放在 Netlify Functions 或自有服务器上。
- 实测免密钥公共文本接口 `text.pollinations.ai`：简单中文请求约 10 秒返回，但内容是与本店无关的餐馆段子；带店名和“不得编造”约束的英文请求约 12 秒返回；加拿大法语请求 30 秒无响应、零字节。整体无可用性承诺，长短随负载波动。
- 该类接口没有服务等级承诺、没有调用方限流保护，也不接受我们的小红书 150 字符与“不得编造经历”约束，最终仍需人工核对，与项目“避免虚构经历”的目标冲突，故不接入；静态演示继续使用本地模板文案。
