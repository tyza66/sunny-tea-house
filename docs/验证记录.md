### GitHub Pages 能力边界与免密钥公共接口实测

- GitHub Actions 只在推送时执行构建，密钥即使注入也会进入公开仓库的构建产物，等于泄露；页面也无法同步等待 workflow 跑完再返回结果。因此 Pages 只能承载静态前端，不能替代服务端，真实 AI 生成必须放在 Netlify Functions 或自有服务器上。
- 实测免密钥公共文本接口 `text.pollinations.ai`：简单中文请求约 10 秒返回，但内容是与本店无关的餐馆段子；带店名和“不得编造”约束的英文请求约 12 秒返回；加拿大法语请求 30 秒无响应、零字节。整体无可用性承诺，长短随负载波动。
- 该类接口没有服务等级承诺、没有调用方限流保护，也不接受我们的小红书 150 字符与“不得编造经历”约束，最终仍需人工核对，与项目“避免虚构经历”的目标冲突，故不接入；静态演示继续使用本地模板文案。

## 暗病审计（2026-09-24）

对照 WCAG AA 自写对比度脚本（Playwright 实时读取计算样式，按祖先链合成背景），对 5 个视口 × 深浅两色共 10 个画面逐一审计文本对比度，并另建 6 种交互状态（生成后、密钥生效后、入口悬停、面板展开、语言菜单展开、陈旧初稿提示）各审计深浅两版：

- 修：`--muted` 两档色值不达标。浅色 `#877c6c` 在 `--bg` 上只有 3.60:1，改为 `#726858` 后得 4.82:1（surface 底 5.16:1）；深色 `#8d8172` 只有 4.08:1，改为 `#9a8f7d` 后得 5.70:1（surface 底 5.25:1）。小字（10–13px）密集处恢复 AA。
- 修：`.byok-count` 与 `.platform.active small` 坐在 `--accent-soft` 底色上，沿用 `--muted` 只有 4.37:1，抬到 `--ink-2`（7.67/8.04:1）。
- 修：`.tea-stamp span` 印章阴刻小字透明度 72% 在朱砂底上仅 3.90:1，提到 88%（5.03:1），深色同步由 72% 提到 95%（4.78:1），阴刻质感保留。
- 修：`.bottom-note b` 的箭头分隔符误用边框色 `--line-strong` 当字色，实际只有 1.54:1 基本隐形，改用 `--muted`。
- 修：自带密钥面板键盘可达性。补 `Esc` 关闭并把焦点还给触发器、打开面板即聚焦密钥输入框、移除密钥后也聚焦输入框；触发器处于禁用态（生成中）时不抢焦点。过程中修掉一个静默失效的真 bug：输入框的 DOM ref 与 `v-model` 变量撞名导致 `focus()` 从未生效，已拆成独立的 `byokInputEl`。

## GitHub Pages 本地设置面板（2026-09-25）

- 动因：GitHub Pages 没有服务端、读不到环境变量，评审者想换服务商或改店名无处可配。右下角新增固定设置按钮（仅静态托管时出现），把「环境变量」搬进本机浏览器：店铺名、城市、Google 索取评价链接、小红书链接、AI 接口地址、模型名与密钥，保存即写入 `localStorage`，页头页脚标题立即更新，刷新后续上，「恢复默认」一键还原。
- 密钥可按需保存：写入前经 XOR + base64 可逆混淆，不明文落盘；输入框与刷新回填均为明文，方便核对；留空保存即从存储移除。混淆是防顺手扫一眼，不是加密强度，公共电脑风险在面板内注明并提供「清除密钥」。
- 服务商泛化到浏览器路径：接口地址接受任意 OpenAI 兼容地址（公网必须 HTTPS，`localhost` 允许 HTTP 自测；粘贴完整端点自动剥掉 `/chat/completions` 与尾部斜杠再归一化），模型名不再限死 DeepSeek、不通时按服务商自己的报错展示，密钥校验改为通用非空（内部空白拒绝、包裹引号剥离）；平台域名白名单（Google、小红书）与 `server/config.js` 保持同一份。
- 修 bug 1：`src/messages.js` 缺 `aiSessionCount` 键，`t()` 兜底把键名本身渲染成「aiSessionCount 0」，五个语言全部补齐。
- 修 bug 2：清除密钥只清了模块内存，`localStorage` 里那份还在，刷新后密钥复活；改为先清存储再清内存。
- 修 bug 3：面板保存时密钥留空会保留存储里的旧 key（`saveSettings` 只合并其余字段）；改为留空即显式清除，端到端断言存储里不再有 `key`。
- 连带修 `server/app.js` 的 CSP：`connect-src` 此前写死 DeepSeek 唯一来源，自定义服务商在本地服务下被拦成「网络连接中断」。改为按模式派生——真实模式只放行 `AI_BASE_URL` 的来源，演示模式放行所有 HTTPS（匹配面板可填任意服务商的行为）；Netlify 与 GitHub Pages 不下发该头，线上不受影响。e2e 此前 2 个失败用例随之转绿，另一个失败是用例自身 mock 路由漏了 `/v1`，已修。
- 测试：新增 `tests/settings.test.js` 14 项（默认值、脏值清洗、保存读取往返、地址归一化、平台白名单、非法地址抛错且不写坏配置、重置、密钥混淆可还原、存储不可用静默失败）；`tests/browser-ai.test.js` 补通用密钥校验与自定义服务商不降级用例；新增 `tests/e2e/settings.spec.js` 5 项，`browser-ai.spec.js` 选择器随面板改版。全套单元 57 项、端到端 23 项通过；`docs/设置面板.png`（390 像素底部抽屉）由端到端重新生成，替换旧「自带密钥面板」截图。
